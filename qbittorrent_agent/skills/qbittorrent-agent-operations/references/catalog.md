# Provider workflow catalog

Load only the skill relevant to the current request.

- [qbittorrent-torrent-lifecycle](../../qbittorrent-torrent-lifecycle/SKILL.md): Manage the qBittorrent torrent lifecycle through the qbittorrent-mcp connector: list and filter torrents, add a torrent to a category, recover a stalled torrent, and prove category writes with a test category. Use when the agent must add, inspect, reannounce, recheck or organize torrents. Do NOT use for speed or ratio limits (qbittorrent-transfer-tuning) or knowledge-graph ingest (qbittorrent-kg-ingestion).
- [qbittorrent-transfer-tuning](../../qbittorrent-transfer-tuning/SKILL.md): Check transfer health and tune qBittorrent's speed and seeding limits through the qbittorrent-mcp connector. Use when the agent must read speeds and stalled torrents, or set global speed limits or per-torrent share limits. Do NOT use to add or delete torrents (qbittorrent-torrent-lifecycle).
- [qbittorrent-download-client](../../qbittorrent-download-client/SKILL.md): Keep qBittorrent working as the download client of the arr media apps through the qbittorrent-mcp connector: diagnose login failures and IP bans, and provision each app's category. Use when Radarr, Sonarr, Lidarr or Chaptarr report the client unavailable or a new app needs a category. Do NOT use to change the apps' own settings (arr-mcp `arr-repair-download-client`).
- [qbittorrent-kg-ingestion](../../qbittorrent-kg-ingestion/SKILL.md): Ingest qBittorrent torrents into the knowledge graph through the qbittorrent-mcp connector as typed Torrent, Tracker and Category nodes. Use when the torrent inventory must be queryable with other sources. Do NOT use to change torrents.
